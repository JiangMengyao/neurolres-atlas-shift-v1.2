# Supplementary materials S1-S8

This directory supports the two-model, 762-case robustness and predictive-uncertainty benchmark.

- `Table_S1_metric_definitions.csv`: fixed performance, calibration, uncertainty, and risk-coverage definitions.
- `Table_S2_reproducibility_receipt.csv`: environments, commits, immutable checkpoint hashes, protocol hashes, and completion receipts.
- `Table_S3_header_anomaly_disclosure.csv`: aggregate disclosure of retained header anomalies.
- `Table_S4_training_evaluation_independence_audit.csv`: training, pilot, and formal identifier-overlap audit.
- `Table_S5_cohort_structure.csv`: source-stratum lesion burden, multiplicity, and center-size structure.
- `Table_S6_multimodel_pairwise_comparisons.csv`: paired two-model estimates by source stratum.
- `Table_S7_uncertainty_calibration_and_risk_coverage.csv`: reliability, entropy-error association, and risk-coverage values.
- `Table_S8_comparator_eligibility.csv`: checkpoint, overlap, feasibility, and execution audit for candidate contemporary comparators.

The archive also contains the frozen v2.0 protocol and all prespecified amendments; performance-blinded qualitative selection records; aggregate source data for Figures 1 and 3-6; R rendering scripts and figure receipts; and `MANIFEST.sha256`. Center labels in the public Figure 5 source are replaced by within-stratum indices, and the public Figure 6 uncertainty-error source is collapsed to the plotted deciles.

The fixed original primary result remains unchanged. Model comparison and uncertainty analyses are explicitly exploratory. Apart from the six pseudonymous qualitative-case selection/display records, no patient-level images, masks, probabilities, full-cohort per-case metrics, source filenames, worker indices, or subject/center linkage records are included in the submission archive.
